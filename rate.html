Rate Underbook

An honest rating, good or bad, helps other travelers decide whether to try Underbook. You rate it in the add-on store you installed it from. Nothing is offered for a rating, and Underbook works the same whether you rate it or not.

Open this page on the computer where Underbook is installed, in the browser you added it to, and it will take you to the right store.

The three stores

  • Chrome Web Store For Chrome, and for Brave, Opera, Vivaldi and other browsers that add extensions from the Chrome Web Store. Opens Underbook's reviews.
  • Microsoft Edge Add-ons For Microsoft Edge, if you added Underbook from Edge Add-ons. If you added it from the Chrome Web Store, rate it there.
  • Firefox Add-ons For Firefox. The rating stars are on Underbook's add-on page once you log in.

Each store asks you to sign in, and may only take a rating from someone who added Underbook from that store. The stores rate the browser extension, so if you only used the price checker on underbook.co, there is nothing to rate. On a phone? Underbook runs in computer browsers, so the store pages are easiest to use on your computer.
