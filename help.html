Which version do I have? The Chrome Web Store, Microsoft Edge Add-ons and Firefox Add-ons each review a new version of Underbook before they serve it, each on its own schedule, so for a while Chrome, Edge and Firefox can run different versions. Your browser updates Underbook by itself once its store serves a new one. Where an answer depends on the version, it says from which version; your browser's extensions page shows yours (Details in Chrome and Edge, about:addons in Firefox).
